This KanyaMart program is a simple C++ online shopping system. It allows users to log in, view products, search for products, and log out.

Simple Description

Product structure: Stores product details like ID, name, category, and price.

Product list: Contains sample products such as kurtis, sarees, makeup kits, laptops, and mobiles.

User database: Stores usernames and passwords using unordered_map.

Login function: Checks whether the entered username and password are correct.

Display Products: Shows all available products with their ID, name, category, and price.

Search Products: Allows the user to search using a product name or category.

Menu: After login, the user can choose:

1. Display Products


2. Search Products


3. Logout



Switch case: Handles the user's menu choice.

Do-while loop: Keeps displaying the menu until the user chooses Logout.


One-line presentation explanation

> “KanyaMart is a C++ shopping management program that provides user login, product display, product searching, and logout functionality using structures, vectors, unordered maps, functions, loops, and switch-case.”
